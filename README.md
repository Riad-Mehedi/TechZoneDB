# TechZoneDB

A SQL Server database for a tech products store, built as part of a structured SQL assignment.

## Database Structure

- **Products** — stores tech items (laptops, phones, audio)
- **Customers** — stores registered customers
- **Orders** — links customers to products (junction table)

## What's Included

| Part | Description |
|---|---|
| Part 1 | Schema design — 3 tables with PKs, FKs, constraints |
| Part 2 | Data population — products, customers, orders |
| Part 3 | UPDATE and DELETE operations |
| Part 4 | Reporting queries using JOINs and aggregations |
| Part 5 | View (`HighValueProducts`) and Stored Procedure (`RegisterCustomer`) |

## How to Run

1. Open **SQL Server Management Studio (SSMS)**
2. Open `Assignment3.txt`
3. Select all → Press **F5**

## Requirements

- SQL Server (any recent version)
- SSMS or any SQL Server compatible client
